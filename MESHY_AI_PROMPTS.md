# HyFable Patreon - Meshy.ai 3D Model Prompts

> **50 prompts x 4 retries each = up to 200 unique models**
>
> All prompts are optimized for Meshy.ai's Text-to-3D pipeline following official best practices:
> single-object focus, Subject + Modifiers + Style structure, specific materials/colors,
> no articulated or multi-jointed designs.

---

## Prompt Best Practices (Quick Reference)

- **Structure:** Main subject + Style details + Other details
- **Do:** Be specific with materials, colors, and style. Focus on one object per prompt.
- **Don't:** Request articulated joints, multiple separate objects, abstract concepts, or fine hair/strand details.
- **Post-generation:** Use Meshy's Smart Healing and Texture Richness tools on the best of your 4 retries.
- **Tip:** Slight rewording between retries can yield dramatically different results.

## Production Strategy

### Workflow Per Prompt
1. **Generate** all 4 retries for each prompt
2. **Compare** the 4 outputs — select the best mesh and texture combination
3. **Refine** using Meshy's Smart Healing for texture imperfections
4. **Adjust** Texture Richness setting before final export
5. **Export** in desired format (FBX, OBJ, GLB) for Patreon delivery

### Patreon Packaging Suggestions
- **Monthly Theme Drops:** Group 8-10 models per month by theme (e.g., "The Undead Horde," "Elven Kingdom," "Dungeon Props")
- **Tiered Access:** Free tier gets 1-2 models, mid tier gets the full set, top tier gets commercial license + source files
- **Bonus Content:** Include the prompt text so patrons can learn to generate their own variations
- **Bundles:** Package related models (e.g., Prompt 33-38 weapons as a "Legendary Armory" pack)
